# StockFlow

### c'est une application web qui permet au entreprise de gérer simplement leur stock avec un historique d'action. Le code est réalisé entierement sans IA , pour prouvez mais aussi acquérir des compétences. 

## Techno Utilisé

- Symfony 7
- React
- Docker

## INSTALLATION

```
git clone https://github.com/Boomwerk/StockFlow.git
```

### Docker : 
```
docker-compose up -d 
```
Vous aurez accés a mailpit sur http://localhost:8025 pour recevoir vos mail de test

### Backend :
Rendez vous dans le dossier backend
```
composer install
```

puis lancez le serveur

### frontend :

Rendez vous dans le dossier frontend

```
npm install 
```
puis lancez le serveur
